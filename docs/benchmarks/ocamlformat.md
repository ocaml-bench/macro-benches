# ocamlformat

OCamlformat is an auto-formatter for OCaml source: it parses a file into an AST
and pretty-prints it back out through a `Format`-box pipeline. Unlike the compiler
benchmarks (`ocamlc_self_compile`), where each module is compiled and discarded so
the live set stays bounded, ocamlformat holds the **whole file's AST plus the
output document in memory at once**, so live heap and RSS grow with the input.

## Ladder

The ladder scales the **size of the formatted source** (number of lines). The
rung inputs `wl_{12,30,150}x.ml` are generated by `ocamlformat.build.sh`
(N-times concatenation of the real `workload.ml`, valid input since ocamlformat
only parses and reprints syntax) and gitignored; only the ~130 KB `workload.ml`
is vendored. Measured on OCaml 5.5.0, Ryzen 9 9950X (`fingerprint.sh` `v=0x400`;
olly gc%/pause from `perf_grp1|re-25|md-2`):

| rung | input | lines | wall | RSS | gc% | max pause |
| --- | --- | --- | --- | --- | --- | --- |
| `_small` | `wl_12x.ml` | ~40k | 4.7s | 0.6 GB | 32.6% | 5.2 ms |
| `_default` | `wl_30x.ml` | ~100k | 12.7s | 1.7 GB | 31.9% | 12.7 ms |
| `_large` | `wl_150x.ml` | ~500k | 90s | 8.8 GB | 28.6% | 90.3 ms |

RSS grows ~linearly and wall slightly super-linearly (~n^1.2); the promotion
fraction holds steady at ~10 %. Where zarith / frama-c / owl see gc% *fall* as
inputs grow, ocamlformat holds a **constant ~30 % gc%** at every size — uniformly
minor-GC-heavy (transient `Format` boxes). At the same time the **max pause climbs
to ~90 ms at `_large`** (p99.9 ~25 ms) — the largest single GC pause anywhere in
the suite — as each major slice scans a multi-GB live AST: a dual signal of steady
minor-GC throughput plus growing major-GC scan latency. It tends to move with the
other AST-shaped benchmarks (`liq_parse_typecheck`) and heavy `Format` users
(`sedlex_tokenize`). A huge band (~450x, ~26 GB RSS) is reachable but deferred.

## Legacy

Kept for reference, not run by default (`RUNNING_TAG=legacy`):

- `ocamlformat_rocq` — the original fixed-input bench, formatting `workload_5x.ml`
  (~663 KB, ~16600 lines extracted from the Rocq prover source).

## Notes

- The `.ocamlformat` file here is empty (default profile). ocamlformat only formats
  a file if it finds a project root at or above it, so the rung inputs must live in
  this directory beside `.ocamlformat`, or it copies the input through unchanged.
- The output binaries are standalone copies, not wrapper scripts.
